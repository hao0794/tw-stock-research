# 台股量化研究：用回測檢驗交易想法

起點是一份讓 AI 盯盤的 prompt：盤中出現「爆量突破」就發買進警報，盤後產出次日強勢股名單。在真正使用之前，我想先知道這套條件**到底有沒有用**，於是改用 Python 串接富果（Fugle）行情 API，抓全市場資料自己計算指標、回測驗證。

結果是：**這套條件扣掉交易成本後，沒有穩定的隔日優勢**。之後的研究方向也從「找買點」轉向「風險控管」與「資產比較」。

> 本專案為個人學習研究，所有結果只描述歷史資料，不構成投資建議。

## 研究流程

| 階段 | 問題 | 腳本 |
|---|---|---|
| 1. 資料來源 | 富果免費方案能拿到哪些資料？速度與頻率限制如何？ | `01_data_source/` |
| 2. 盤後篩選 | 把 prompt 的條件寫成程式，每天篩出符合的股票 | `02_screening/screen.py` |
| 3. 策略回測 | 這些股票隔天真的會漲嗎？換不同進出場方式呢？ | `03_backtest/` |
| 4. 風險與動能 | 低回撤股票有哪些？動能選股贏得過 0050 嗎？出場規則有用嗎？ | `04_risk_momentum/` |
| 5. 資產比較 | 高股息 ETF、同指數 ETF、美股個股和大盤比起來如何？ | `05_etf_comparison/` |

## 主要發現

### 1. 爆量突破條件沒有隔日優勢

`03_backtest/analyze2.py`：839 檔上市股票、120 個交易日（2026-04-07 ～ 2026-09-24），每筆扣 0.5% 交易成本。

條件：收盤 > 25 元、5MA > 10MA > 20MA、成交量 > 20 日均量 2 倍、漲幅 4%～9.5%、上影線 ≤ 10%。另外測一組全部放寬的版本，增加樣本數。

| 進出場方式 | 放寬組（290 筆） | 原始條件（77 筆） |
|---|---|---|
| 今日收盤買、隔日開盤賣 | −0.09%（前 +0.29% / 後 −0.76%） | −0.30% |
| 今日收盤買、隔日收盤賣 | −0.34%（前 +0.06% / 後 −1.05%） | −0.06% |
| 今日收盤買、持有兩天 | +0.10%（前 +0.62% / 後 −0.84%） | +0.66%（前 +1.36% / 後 −0.48%） |
| 隔日開盤買、當日收盤賣 | −0.75% | −0.24% |
| 隔日突破前高買、當日收盤賣 | −0.56% | −0.19% |

（數字為扣成本後的平均報酬；「前／後」為把回測期間切成兩半，各自的平均）

- **24 個組合中，沒有任何一個在前後兩段都賺錢。**
- 唯一看起來不錯的「持有兩天」只在前半段有效。一次比較 24 種組合，靠運氣也會出現一兩個好看的結果，所以不採信。
- 加上停損（2%、3%、5%）也沒有讓任何組合轉正，停損越緊，中位數越接近「停損 + 成本」，代表常被洗出場。

**結論**：篩選結果只當觀察名單，不當買進訊號。

### 2. 動能選股沒有穩定贏過 0050

`04_risk_momentum/momentum.py`：流動性足夠的股票（近 60 日平均 ≥ 3,000 張），每月依過去 3、6、12 個月報酬排名，持有 1 或 3 個月，約 34 個月的資料。

- 前 20%、前 10% 對全體股票有約 0～2% 的超額，但多數組合前半段為 0 或負、後半段才轉正，更像行情影響。
- **對 0050 的超額全部為負**，扣成本前就是 −0.3% 到 −3.8%。
- 只買動能第 1 名一檔：持有 3 個月平均 +5.6%～+9.6%，但中位數為負，最差 −39%～−47%，贏過 0050 的月份只有約 24%～41%。平均報酬被少數暴漲拉高。

### 3. 出場規則在上漲行情中都輸給買進持有

`04_risk_momentum/check5.py`：5 檔低回撤候選股，約 3 年資料，進場條件為收盤站上 20 與 60 日均線，測 6 種出場規則。

| 股票 | 年化波動 | 跌破 60 日均線出場（筆數／累積） | 買進持有 |
|---|---|---|---|
| 2884 玉山金 | 22% | 12 筆 / +75% | +108% |
| 2887 台新新光金 | 31% | 25 筆 / +68% | +171% |
| 2412 中華電 | 12% | 18 筆 / +3% | +36% |
| 2892 第一金 | 18% | 30 筆 / +5% | +70% |
| 2801 彰銀 | 18% | 30 筆 / +12% | +89% |

- 這段期間以上漲為主，出場規則的價值（擋大跌）沒有機會發揮。
- 20 日均線對低波動股太敏感：中華電 3 年做了 54 筆、平均持有 7 天，成本就吃掉約 27%。
- 8% 硬停損幾乎沒被觸發，對這幾檔只是極端情況的保底。

### 4. 資產比較

`05_etf_comparison/`：價格已還原除權息，假設股利再投入。

| 比較 | 期間 | 結果 |
|---|---|---|
| 00919 vs 0050 | 2022-10 ～ 2026-10 | 含息總報酬 +225% vs +393%；最大回撤 23.4% vs 27.5%；相關係數 0.71 |
| 006208 vs 0050 | 約 10 年 | 追蹤同一指數，報酬幾乎相同，差距主要來自費用與追蹤誤差 |
| ADBE vs S&P 500 | 1～15 年 | 使用 yfinance 取得美股資料，比較不同期間的含息報酬與回撤 |

高股息 ETF 的配息不是額外多賺的錢：除息當天股價會扣掉同樣金額，高殖利率只代表報酬有較多以現金形式拿回。

## 方法上的處理

- **價格還原權息**：用富果回傳的 `change` 反推每日參考價，計算還原價；並偵測 0050 在 2025-06 的 1 拆 4 分割，避免被當成暴跌。
- **交易成本**：每筆來回扣 0.5%（手續費 + 證交稅概估）。
- **台股升降單位**：觸發價、停損價都調整成合法價位。
- **樣本外檢查**：把回測期間切成前後兩半，兩段都成立才算穩定。
- **日 K 的限制**：同一天內無法判斷先碰到停損還是先突破，涉及停損的結果採保守算法並註明。
- **API 頻率限制**：下載結果存成本機快取，可中斷續跑；被限流時自動等待重試。

## 已知限制

- 回測期間短（半年到 4 年），且是台積電與 AI 領漲、0050 特別強的行情，換一段時間結果可能不同。
- 股票母體以「今天」的流動性條件挑選，有倖存者偏差。
- 動能與出場測試的價格不含現金股息。
- 3 個月持有的觀察期彼此重疊，獨立樣本比表面上少。

## 使用方式

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
export FUGLE_API_KEY="你的富果 API key"   # 只放在環境變數，不要寫進檔案

python 02_screening/screen.py            # 當日盤後篩選
python 03_backtest/backtest2.py          # 下載約一年的全市場日 K 並回測（第一次約 5～8 分鐘）
python 03_backtest/analyze2.py           # 用快取比較 12 種進出場方式
python 04_risk_momentum/screen_risk.py   # 流動性與最大回撤篩選
python 04_risk_momentum/momentum.py      # 動能選股 vs 0050（約 15～30 分鐘）
python 04_risk_momentum/check5.py        # 指定股票的出場規則測試
python 05_etf_comparison/etf_compare2.py 006208 0050 10   # 任兩檔比較，最後一個參數為年數
```

快取與輸出檔會存在 `~/fugle/cache*` 和 `~/fugle/output`。`results/` 內是先前執行的輸出範例。

## 資料來源

- [富果 Fugle 行情 API](https://developer.fugle.tw/)（免費方案）：個股歷史日 K
- [臺灣證券交易所 OpenAPI](https://openapi.twse.com.tw/)：全市場當日成交資料、股票名稱
- [Yahoo Finance](https://finance.yahoo.com/)（透過 yfinance）：美股與匯率
